# 结论.md

把一些测试得到的重要结论写在这里

## NQ

1、5分钟NQ与ES同步，则可以做debit call spread, 5DTE，0.6-0.4，而且uturn_btm_level = 1即可，收益风险比可达32，最大回撤为7.9%，而反直觉的是：
> <mark>1分钟和15分钟上，NQ与ES同步，效果都不好</mark>

2、NQ与SMH同步去做nq debit call spread，收益风险比虽然能达到13，但是最大回撤超过-10%，效果不好。

3、NQ与SMH同步去做nq credit put spread, 1M和5M上都是不行的，收益风险比尚可，但最大回撤太高。除非采用3级ubottom，但那样交易次数又太少。

> <mark>NQ与ES同步时，只可以在5M上对NQ 交易debit call spread, 要想做credit put spread，必须符合而且uturn_btm_level = 1,M1和M5都可以，但两者的交易机会都很少
></mark>
